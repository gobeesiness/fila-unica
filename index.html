Onde está o dado

Esta tela não guarda nada. A fonte é go-beesiness-regras/dados/tarefas.json, em git. Se esta app sumir, o dado continua lá.

Como criar o token — 4 passos

É o token clássico com escopo repo — decisão do CTO em 04/08/2026, e o motivo está na nota abaixo.

  1. Abra github.com/settings/tokens/new (Settings → Developer settings → Personal access tokens → Tokens (classic)).
  2. Em Note, escreva algo que se reconheça depois — fila-unica.
  3. Em Expiration, ponha 30 dias. Token que não vence é token que ninguém revoga.
  4. Marque apenas a caixa repo — a de cima, que já inclui as de dentro. Não marque mais nada. Generate token, e copie: o GitHub mostra o valor uma única vez.

Por que o clássico, e não o fine-grained. O fine-grained limitaria o token a um repositório, mas em organização ele precisa do aval de um owner — e enquanto o pedido estiver pendente o token existe e não funciona, com o GitHub respondendo 404, o mesmo código de “não existe”. Como o CTO e o CEO já enxergam todos os repositórios, o escopo repo não lhes concede nada de novo: não é escalada de privilégio. O que muda é o raio de alcance se o token vazar — e é por isso que a validade é curta e a tela confere, ao conectar, se você não marcou caixa a mais.

Sem token ela não carrega o backlog — o repositório é privado. O botão do disco existe só para abrir um .json que você já tenha; ele não fala com o git. ⚠️ Se marcar “lembrar”, ele fica no localStorage desta máquina.
