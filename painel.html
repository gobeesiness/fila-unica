🐝 Painel da fila única

Onde está o dado

Este painel não guarda nada e não escreve nada. A fonte é go-beesiness-regras/dados/tarefas.json, em git. Quem edita é a tela (app/index.html); aqui é só leitura.

Como criar o token — 4 passos

É o token clássico com escopo repo — decisão do CTO em 04/08/2026. É o mesmo token da tela; se você já usa a tela neste navegador, ele já está aqui.

  1. Abra github.com/settings/tokens/new (Settings → Developer settings → Personal access tokens → Tokens (classic)).
  2. Em Note, escreva algo que se reconheça depois — fila-unica.
  3. Em Expiration, ponha 30 dias. Token que não vence é token que ninguém revoga.
  4. Marque apenas a caixa repo — a de cima, que já inclui as de dentro. Não marque mais nada. Generate token, e copie: o GitHub mostra o valor uma única vez.

Por que repo se o painel só lê. Repositório privado exige repo no token clássico — não existe escopo “ler privado” separado. O painel usa só o verbo GET: não há um único PUT, POST, PATCH ou DELETE nesta página, e isso é conferido por teste automático.

Sem token ele não carrega o backlog — o repositório é privado, e não há caminho offline: o painel lê sempre do git, nunca de um arquivo solto, para que ninguém decida sobre uma cópia vencida. ⚠️ Se marcar “lembrar”, ele fica no localStorage desta máquina.
